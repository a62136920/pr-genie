PR Genie ✨

用 AI 自动生成 PR 描述和 Release Notes。零服务器，5 分钟接入，支持 OpenAI / DeepSeek 等兼容 API。

GitHub 仓库 快速开始

功能

  • PR 打开 → 自动评论：概要 / 变更 / 测试建议 / 风险
  • 推送 tag → 自动生成 Release Notes
  • 中英文输出 · 自定义 Pro 模板

快速接入

name: PR Summary
on:
  pull_request:
    types: [opened, synchronize, reopened]
jobs:
  summarize:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: a62136920/pr-genie@v0.1.0
        with:
          mode: pr-summary
          api-key: ${{ secrets.OPENAI_API_KEY }}
          language: zh
